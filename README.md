> The Python-first, developer-obsessed open-source toolkit for building

## Why Viora?

[3-4 sentences. Talk directly to the developer reading this. "If you've 
tried to integrate ABDM, you know the pain: webhook async flows, FHIR R4 
bundle generation that doesn't validate, 5-second callback timeouts that 
fail certification, and no good way to test locally without a sandbox 
access. Viora fixes this."]

## Features (v0.1 roadmap)

- [ ] FHIR R4 bundle generation for core ABDM care contexts
- [ ] Async webhook handler with guaranteed callback reliability
- [ ] Local mock ABDM gateway for offline development
- [ ] Pydantic models for all ABDM API request/response types
- [ ] Example FastAPI integration
- [ ] Docker Compose dev environment
